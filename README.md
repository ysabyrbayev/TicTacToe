# Tic-Tac-Toe

A console-based Tic-Tac-Toe game written in C++. This was my first C++ project, built while following [this tutorial](https://www.youtube.com/watch?v=mNvIqaRFBts) by Kenny Yip.

Two players (X and O) take turns entering a row and column to place their mark on a 3x3 board. The game prints the board after every move and detects a win (row, column, or diagonal) or a tie.

## Running it

```
clang++ TicTacToe.cpp -o TicTacToe
./TicTacToe
```

Then enter a row and column from 0-2 when prompted, e.g. `1 2`.
